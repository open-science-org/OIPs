## Abstract

Legacy OIP, originally written as GitHub issue #8. It proposes IdeaBoard, a web page with a collection of themed boards for discussing research ideas and news, sharing core code with peer review and public review, and serving as the first version of public review.

## Specification

None. The original text is in [issue #8](https://github.com/open-science-org/OIPs/issues/8).

## Rationale

A discussion board is a low-cost way to start public review and attract users before formal review exists.

**Later developments.** The v1 design includes chat about each idea on its idea page.

## Security Considerations

Not discussed in the issue. Moderation and spam would need to be addressed.
