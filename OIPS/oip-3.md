## Abstract

Legacy OIP, originally written as GitHub issue #5. OSO needs funding to grow, but investors usually expect something in return, such as a share of OSO tokens, which could concentrate token ownership in a few entities. The issue asks which funding options OSO should accept.

## Specification

None. The original text and discussion are in [issue #5](https://github.com/open-science-org/OIPs/issues/5).

## Rationale

The discussion proposed one path: register OSO as a non-profit in the USA, set up a joint account and crypto wallets for an OSO fund, explain on the website why benevolent funding is needed, and meet potential donors.

**Later developments.** [OIP-8](./oip-8.md) addresses token concentration by allowing no pre-mine beyond a disclosed bootstrap pool and by never deriving voting weight from token holdings. The v1 roadmap places a legal entity and first outside funding at milestone M3.

**Related past work.** [Proof of Idea v0.0 (2018), §1](https://github.com/open-science-org/wiki/blob/52ba175b3bc57a8c08297c4e4a3db835ea2edbde/Proof_of_Idea.pdf) ("no pre-mined assets"); [admin issue #7](https://github.com/open-science-org/admin/issues/7) (a multisig wallet for OSO funds); [OIP-2](./oip-2.md). Now covered by [OIP-8](./oip-8.md) sections 10 and 11.

## Security Considerations

Concentrated token ownership could give funders control over OSO if tokens carried voting power.
